# auditpack

Audit CSV/TSV pack tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/auditpack/

## Install / run

```bash
git clone https://github.com/theworker02/auditpack.git
cd auditpack
node src/cli.js
node --test
```
